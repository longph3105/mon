## `ImageFolder`

- New `mon.data.dataset.ImageFolder(source, mode=, transform=, recursive=True, exts=)`: unregistered dataset
  for prediction. `source` = folder (recursive, sorted, default exts = decodable images), one file, or a list
  (order kept). Samples `{"image", "meta"}`, `meta.split = PREDICT`, `meta.stem` = relative path without
  suffix (outputs mirror the tree). Raises on missing files, non-images, empty input, and duplicate stems
  (outputs would overwrite each other).
- `_index_dir` (shared with `FolderDataset`) skips hidden paths: macOS writes `._name` AppleDouble files on

- Replaces mon_old predictor input handling; the save-dir side (`resolve_save_dir`, drop `near_src`) stays
  with the predictor port. `docs/data.md` section 5: predict-on-a-folder example (runs in the doc test).

## tv_tensors: benefits, caveats → AGENTS rules

- Verified (torchvision 0.29): per-type dispatch (Mask nearest keeps ids {0,7}; boxes/keypoints rescale and update
  `canvas_size`; plain `labels` untouched), joint geometry incl. Video, `ConvertBoundingBoxFormat`,
  `SanitizeBoundingBoxes` drops labels with degenerate boxes.
- Caveats verified: `ColorJitter` changes every `Image` (input, ground-truth target, depth-as-Image; not Mask);
  in an all-plain-tensor dict only the first tensor is treated as the image (others not flipped); arithmetic and
  `.float()` unwrap to `Tensor`.
- AGENTS.md rules: always wrap image-like values (class maps `Mask`, continuous maps incl. depth `Image`);
  two-stage transforms (geometric on sample, photometric on input keys via `ApplyTo`, to build in
  `mon.data.transforms`); `SanitizeBoundingBoxes` after crops.
